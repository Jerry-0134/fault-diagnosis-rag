# 工业故障智能问答系统

基于 RAG（检索增强生成）的工业设备故障诊断助手。一线操作员通过自然语言提问，即可获得专业、可操作的故障排查建议。

\### 环境要求

\- Python 3.11+

\- DeepSeek API Key（\[获取地址](https://platform.deepseek.com/)）

## 🚀 核心升级亮点

本项目已从基础关键词匹配全面升级为**混合检索架构**，实现四大核心突破：

| 能力 | 升级前 | 升级后 |
| :--- | :--- | :--- |
| **检索方式** | 纯关键词匹配 | 向量语义(70%) + 关键词(30%) 混合检索 |
| **语义理解** | ❌ 无法理解"发烫"≈"过热" | ✅ 自动语义匹配 |
| **响应速度** | 无缓存，每次调用LLM | 内存缓存，重复查询 **0.16ms** |
| **可观测性** | 无 | 实时性能面板（平均/P95/缓存命中率） |
| **输入方式** | 仅文本 | 文本 + 图片（多模态） |

**量化成果**：
- 检索准确率：从 **50% 提升至 100%**（+100%）
- 重复查询响应：从 **13 秒 优化至 0.16 毫秒**（优化 82,000 倍）
- 支持 50+ 工业故障案例（变频器、PLC、电机、传感器、CNC、液压、气动等）

## 🏗️ 系统架构

| 层级 | 技术 | 说明 |
| :--- | :--- | :--- |
| **前端** | Streamlit | Web 交互界面，支持文本与图片混合输入 |
| **检索层** | **混合检索** | 向量检索(70%) + 关键词检索(30%) 融合语义理解与精确匹配 |
| **向量引擎** | Sentence-Transformers + FAISS | 使用 `BAAI/bge-small-zh-v1.5` 中文模型，将知识库嵌入 512 维向量空间 |
| **大模型** | DeepSeek API | 基于检索上下文生成专业、可解释的诊断建议 |
| **知识库** | data.txt | 包含 50+ 工业设备故障案例 |
| **缓存** | 纯 Python 内存缓存 (LRU) | 高频问题秒级响应，重复查询性能优化 |
| **监控** | 自定义装饰器 | 实时采集与展示平均耗时、P95 分位耗时、缓存命中率 |
| **多模态** | 轻量级 OCR + VLM | 支持从**图片文件名**提取故障关键词，模拟图文混合诊断流程 |

## ✨ 核心亮点

### 1. 混合检索（语义 + 精确）
结合向量语义理解与关键词精确匹配，在 4 类典型故障查询上，准确率从纯关键词的 **50% 提升至 100%**。系统能准确理解"电机发烫"与"电机过热"为同一类故障。

### 2. 性能优化（缓存 + 监控）
- **LRU内存缓存**：相同问题直接返回，跳过检索和LLM调用
- **TTL自动过期**：缓存1小时后自动清理
- **实时监控面板**：平均耗时、P95耗时、缓存命中率一目了然

| 场景 | 响应时间 | 提升倍数 |
| :--- | :--- | :--- |
| 首次查询 | 13 秒 | - |
| 缓存命中 | **0.16 毫秒** | **82,000 倍** |

### 3. 多模态支持（图文混合诊断）
- 支持上传 JPG/PNG 图片
- 从文件名自动提取故障关键词（如 `变频器过流.jpg` → "过电流"）
- 图片分析结果自动融合到文本查询
- 轻量级实现，无需下载重型模型

### 4. 工程化与落地思维
- **零重型依赖**：仅 Python 基础库，无需 Docker/Redis
- **离线优先**：所有模型缓存本地，适配工厂网络受限场景
- **调试友好**：内置调试面板，显示综合分、向量分、关键词分
- **三级降级策略**：完全匹配/部分匹配/无匹配，保证鲁棒性

## 📊 评估结果

以下为混合检索与关键词检索的对比实验数据（基于 4 个典型查询）：

| 查询 | 关键词检索 | 混合检索 (本系统) |
| :--- | :---: | :---: |
| 变频器过电流 | ✅ | ✅ |
| 电机发烫 (语义匹配) | ❌ | ✅ |
| PLC 连不上了 | ✅ | ✅ |
| 电机振动很大 | ❌ | ✅ |
| **综合准确率** | **50%** | **100%** |

**结论**：混合检索在保持精确匹配能力的同时，新增语义理解能力，准确率实现翻倍提升。


## 💰 业务价值分析

本系统面向工业制造企业，旨在替代传统人工故障排查流程。基于典型场景估算：

- **传统方式**：专家查阅手册 + 电话咨询，平均耗时 **2 小时/次**
- **本系统**：文本/图片输入，AI 生成诊断，平均耗时 **10 秒/次**
- **效率提升**：**720 倍**

**附加价值**：
- 降低对资深专家的依赖，新员工也可快速诊断
- 故障知识持续沉淀，形成企业数字资产
- 支持图片上传，未来可接入巡检机器人自动识别

> 注：以上为基于公开行业数据的理论估算，实际收益因工厂规模、故障频次而异。
